# Employee Management System
This is a console-based Employee Management System developed using Java.

The application allows users to:
- Add employees
- View all employees
- Search employees by ID
- Remove employees

The project demonstrates:
- Object-Oriented Programming (OOP)
- Java Collections Framework
- Java 8 Optional
- Stream API
- Custom Exceptions

## Concepts Used
- Classes and Objects
- Constructors
- Encapsulation
- ArrayList
- Optional
- Stream API
- Exception Handling

## Project Structure

EmployeeManagementSystem/
│
├── Employee.java
├── EmployeeManager.java
├── EmployeeNotFoundException.java
├── Main

## Features

 Add Employee
 View Employees
 Search Employee
 Remove Employee
 Custom Exception Handling (Displays custom error message when employee is not found.)


## How to Run

1. Open project in VS Code
2. Compile all Java files
3. Run Main.java
4. Use menu options in console
