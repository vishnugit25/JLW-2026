# Multithreading File Processing Application

## Overview

This project is a multithreaded file processing application developed using Java.

The application:

* Reads data from multiple text files
* Processes file content using threads
* Writes processed data into output files
* Logs processing results



## Technologies Used

* Java
* BufferedReader
* BufferedWriter
* Multithreading



## Project Features

* Multithreaded file processing
* File reading and writing
* Logging support
* Clean and modular code structure



## How to Run

1. Open project in VS Code
2. Place input files inside the `src` folder
3. Run `Main.java`
4. Check generated output files
