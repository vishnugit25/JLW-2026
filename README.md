Library Management System
Overview

This project is a simple Library Management System developed using Java.
It demonstrates the use of Object-Oriented Programming (OOP) concepts, Java Collections Framework, Exception Handling, Lambda Expressions, and Streams.

The system allows users to:

Add books
Display books
Issue books
Return books
View available books
Technologies Used
Java
VS Code
Java Collections Framework

Features
Add Book
Add User
Display Books
Issue Book
Return Book
Display Available Books
Interactive Console Menu
Exception Handling
Java 8 Lambda Expressions
Java Streams API
